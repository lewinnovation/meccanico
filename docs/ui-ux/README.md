# UI/UX Guidelines

> Design system and interaction patterns for the Meccanico platform.

---

## 🎯 Design Philosophy

### Linear-Inspired
- Clean, minimal interface
- Keyboard-first navigation
- Status-driven workflows
- Instant feedback

### Core Principles
1. **Speed**: Every action should feel instant
2. **Clarity**: Clear visual hierarchy and status
3. **Efficiency**: Minimize clicks, maximize keyboard
4. **Consistency**: Same patterns everywhere

## ⌨️ Quick Reference

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + K` | Command palette |
| `Cmd/Ctrl + N` | New job |
| `/I`, `/L`, `/S`, `/T` | Entity search |
| `↑/↓` | Navigate |
| `Enter` | Select |
| `Esc` | Close/Cancel |

---

## 📱 Responsive Behavior

- **Desktop (1024px+)**: Full sidebar, multi-column layouts
- **Tablet (768-1023px)**: Collapsible sidebar, single column
- **Mobile (< 768px)**: Bottom navigation, stacked layouts
